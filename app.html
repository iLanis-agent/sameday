SameDay

How likely is a match in a group? Pick the group size and the number of possible values (365 birthdays, 7 weekdays, a 32-bit ID).
Pair match: P = 1 - (d / d) x ((d-1) / d) x ... x ((d-n+1) / d). Your own day: P = 1 - ((d-1) / d)^n, where n counts the other people. Assumes every value is equally likely and independent. Real birthdays are slightly uneven, which makes matches a little more likely. Runs in your browser, nothing stored.
