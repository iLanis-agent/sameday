23 people: 50.73% that some pair matches, but only 5.9% that anyone matches you (you plus 22 others). A 32-bit ID hits 50% collision risk at just 77,164 items.

What it does

  • Pair-match and match-you odds for any group size
  • Any number of possible values: months, weekdays, dice, codes, IDs
  • The group size you need for a target chance
  • Expected number of matching pairs
Formulas and checkpoints from Wikipedia, Birthday problem (23 people = 50.7297%, 253 to match you). Assumes equal, independent values. Static, client-side, nothing stored. Source
